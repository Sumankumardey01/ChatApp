# ChatApp – Web & Android Messaging Application

A WhatsApp-inspired messaging application built with **Python, Django, and Android**. The project aims to provide a simple messaging experience across web browsers and Android devices.

> **Project Status:** Under Development 🚧

## Overview

ChatApp is a messaging application project designed to explore web development, backend engineering, database management, and Android application development.

The project includes a Django-based web backend and an Android application.

## Technology Stack

| Component | Technologies |
|---|---|
| Backend | Python, Django |
| API | Django REST Framework |
| Database | SQLite |
| Real-time communication | Django Channels, WebSockets |
| Frontend | HTML, CSS, JavaScript |
| Android | Kotlin |
| Version Control | Git, GitHub |

## Getting Started

### Requirements

- Python
- Django
- Android Studio (for Android development)
- Git

### Run on macOS

1. Download or clone the repository.
2. Open the project folder.
3. Follow the instructions in `START_HERE.txt`.
4. Use `setup_mac.command` for the setup process.
5. Use `run_web.command` to start the web application.

For real-time ASGI development, refer to `run_asgi.command`.
